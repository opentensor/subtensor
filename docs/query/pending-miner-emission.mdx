Accrues each epoch when `ClaimBasedMinerEmissions` is enabled; claim it
with the `claim_miner_emission` intent. Zero when claim mode is off or
nothing is pending.

**Category:** Staking

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `hotkey_ss58` | string | Mining hotkey whose pending incentive to read. |
| `netuid` | integer | Subnet the incentive was earned on. |
