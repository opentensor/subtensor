When claim-based miner emissions are enabled for the subnet, epoch
distribution accrues miner incentive into `PendingMinerAlpha` instead of
staking it every tempo. The coldkey that owns `hotkey_ss58` calls this
to stake the pending balance. An alpha fee proportional to the call's
weight is recycled from the pending amount before the remainder is
staked (or auto-staked to the coldkey's destination on that subnet).
Validator dividends are unchanged and are never claimed through this
extrinsic. Preview the pending amount with the `pending_miner_emission`
read. Claims remain available after an emergency disable of
`ClaimBasedMinerEmissions` (that toggle only stops new epoch accrual).
Fails with `AmountTooLow` when nothing is pending.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `netuid` | integer | yes | Subnet the incentive was earned on. |
| `hotkey_ss58` | string | no | Mining hotkey with pending incentive. Defaults to the wallet's own hotkey. |

Address parameters (`--hotkey`, `--coldkey`, `--dest`, ...) accept a raw ss58
address, an address-book or proxy-book name, or a local wallet/hotkey name.

## CLI

Preview with `--dry-run` (shows fee, effects, and policy result without
submitting), then submit:

```bash
btcli tx claim-miner-emission \
  --netuid <int> --dry-run
btcli tx claim-miner-emission \
  --netuid <int> -w my_coldkey
```

## Python

```python
import bittensor as bt
from bittensor.wallet import Wallet

wallet = Wallet(name="my_coldkey", hotkey="my_hotkey")
intent = bt.ClaimMinerEmission(netuid=1)

sub = bt.Subtensor()
plan = sub.plan(intent, wallet)   # fee, effects, policy — no submission
result = sub.execute(intent, wallet)
if not result.success:
    print(result.error.code, result.error.remediation)
```

(`bt.Subtensor` is also the async client — `async with bt.Subtensor() as client:`
— see [The client](/docs/concepts/client).) Or build the intent by op name, as
an agent would:

```python
result = sub.execute_tool("claim_miner_emission", {...}, wallet)
```
