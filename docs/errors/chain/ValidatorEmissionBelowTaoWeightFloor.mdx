Slot 3 (validator) of the emission weight vector is below the subnet's TAO-weight floor `V0 * TaoWeight`, where `V0` is the subnet's base validator share (0.41 on mainnet subnets with the owner cut, 0.50 without). Lowering the validator share scales the subnet's TAO weight by `V0 / V` so root holders keep their payout; below the floor that scaled weight would exceed 1, and a validator share of 0 would need an infinite TAO weight, so it is always rejected. Read the current floor with `btcli subnets emission show --netuid <n>` and keep the validator share at or above it.

Declared by the `SubtensorModule` pallet; it classifies to the semantic code [`policy_violation`](/docs/errors/policy-violation).
